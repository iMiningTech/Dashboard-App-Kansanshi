iMining ATLAS — Navigation Icons

Seven duotone icons matched to the ATLAS app icon palette. Designed for ~24-32px in a side navigation, each holds together down to 24px with a clear, distinct silhouette.

Active state pattern: tinted orange background (rgba(247,148,29,0.14)), white label, plus a 4px orange accent bar on the right edge of the row. The icon itself does not change between states — the surrounding chrome carries the state.

Icon size in nav: 22px is the sweet spot for desktop sidebars. Use the 48px PNG and let the browser downscale, or use the SVG directly (recommended) which stays crisp at any size.

Recommended order: Dashboard, Assets, Sites, Maintenance, Tickets, Inventory, Reports. This follows the natural data flow — overview, the "what", the "where", the "history", the "to-do", the "stock", the "results".

Integration

React component (recommended — uses SVG directly)
// icons/NavIcon.tsx
import Dashboard   from '@/assets/nav/nav-01-dashboard.svg';
import Assets      from '@/assets/nav/nav-02-assets.svg';
import Sites       from '@/assets/nav/nav-03-sites.svg';
import Maintenance from '@/assets/nav/nav-04-maintenance.svg';
import Tickets     from '@/assets/nav/nav-05-tickets.svg';
import Inventory   from '@/assets/nav/nav-06-inventory.svg';
import Reports     from '@/assets/nav/nav-07-reports.svg';

export const NAV_ICONS = {
  dashboard: Dashboard,
  assets: Assets,
  sites: Sites,
  maintenance: Maintenance,
  tickets: Tickets,
  inventory: Inventory,
  reports: Reports,
} as const;
