iMining ATLAS — App Icon

Asset management with maintenance logging and dashboards. The icon evolves the existing iMining "i" — the dot becomes a globe with site pins, the stem stays identical to the parent brand.

The mark

One primary asset highlighted in upper-left (the focal point), three supporting sites distributed across the globe. The slanted stem bottom is preserved from the original iMining 'i' geometry.

Size system

The icon uses two source SVGs depending on display size. At 16/32/48px the simplified variant (single prominent pin) is used so the icon stays legible. From 64px up the full 4-pin master takes over.

Source SVGs (in this folder)

S
atlas-icon-master.svg
The primary mark — 4 pins, full detail, navy background. Use for everything 64px and up.
S
atlas-icon-no-bg.svg
Same as master, transparent background. Use over light or alternate-color surfaces.
S
atlas-icon-favicon.svg
Simplified — globe ring + 1 center pin + stem. Holds up at 16/32/48px.
S
atlas-icon-maskable.svg
For Android PWA. Background fills edge-to-edge; content sits in the inner 80% safe zone.
